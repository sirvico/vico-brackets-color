# Vico Brackets Color

Colors nested brackets `()`, `[]` and `{}` by depth level, using a soft pastel palette designed for dark themes.

Each nesting level gets its own color, and the opening and closing bracket of a pair always share the same one, so you can see at a glance where a block starts and ends.

## Features

* **Multi-Bracket Support**: Colors `(`, `)`, `[`, `]`, `{` and `}` by nesting depth.
* **Dark Theme Optimized**: Soft pastel palette designed to stay readable on dark backgrounds.
* **Universal IDE Support**: Works in every JetBrains IDE: IntelliJ IDEA, CLion, PyCharm, WebStorm, GoLand, Rider, PhpStorm, and others.
* **Language Independent**: Behaves consistently across C/C++, Java, Kotlin, Python, JavaScript, and more.
* **Smart Filtering**: Automatically ignores brackets inside comments and string literals.
* **High Priority**: Draws above the theme's default syntax and semantic highlighting so colors are never overridden.

## Installation

### From JetBrains Marketplace
1. Open **Settings / Preferences** → **Plugins** → **Marketplace**.
2. Search for **Vico Brackets Color**.
3. Click **Install** and restart the IDE.

### From Disk
1. Download the `.zip` from the [Releases page](https://github.com/sirvico/vico-brackets-color/releases).
2. Open **Settings / Preferences** → **Plugins** → ⚙ (Gear icon) → **Install Plugin from Disk...**
3. Select the `.zip` file and restart the IDE.
